# PSPM Chemistry Portal — Teal Blue & White

This package contains the current portal, its single chapter-coverage analysis,
and the original examination PDFs. No installation or build is required.

## Choose your download

- PSPM-Portal-standalone.html: a single file with styling, scripts, and all six
  examination PDFs embedded. Open it in your browser. To publish this version,
  rename it to index.html and upload it to the root of your repository.
- PSPM-Portal-GitHub-Render.zip: recommended for hosting. Extract it and upload
  the CONTENTS of the pspm-portal folder to the root of your GitHub repository.
  Keep the papers folder and all files together. Do not upload only the ZIP.

## GitHub Pages

1. Create a repository and upload the extracted website files to its root.
2. Open Settings → Pages → Deploy from a branch.
3. Select your uploaded branch (usually main) and /(root), then Save.
4. Open the website URL shown by GitHub after deployment finishes.

Official guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Render

1. Upload the extracted website files to the root of a GitHub repository.
2. On Render, choose New → Static Site and connect that repository.
3. Choose the branch containing the website files.
4. Root Directory: leave blank.
5. Build Command: echo "No build required"
6. Publish Directory: .
7. Click Create Static Site and open the onrender.com URL when ready.

These settings assume index.html is at the repository root. If you keep the
pspm-portal folder in the repository, use pspm-portal as Publish Directory.

Official guide: https://render.com/docs/static-sites
